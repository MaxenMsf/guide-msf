Rejoindre le discord

Marvel Strike Force est un jeu en évolution constante et des infos postées dans ce guide peuvent être obsolètes. Si vous avez des doutes, n'hésitez pas à rejoindre le discord et poser toutes vos questions en cliquant sur l'image.

Trouver une alliance

Rejoindre une alliance est primordial pour avancer dans le jeu. Le raid étant le mode de jeu donnant le plus de récompenses, je vous donne le lien du mercato — un serveur Discord qui met en relation recruteurs et joueurs en recherche d'alliance, pour tous les niveaux.

Créer un compte msf.gg

Msf.gg permet de gérer son roster facilement. Certaines alliances l'utilisent mais le plus important sont les cadeaux gratuits et les avancées dans les phases. Créer un compte et le lier à son compte en jeu est très important.

Il y a 4 codes permanents à entrer dans "Cadeau de joueur" :

ZOMBIE — FOUR — GHOSTRIDER — SPIDERMAN

Attendez deux minutes entre chaque code.

Utiliser ses ressources

Les noyaux sont une ressource rare. Le meilleur moyen de les dépenser n'est pas d'ouvrir des orbes, mais d'acheter les recharges d'énergie jusqu'à 100 noyaux (4 recharges à 50 noyaux = 200 noyaux/jour).

Dépenser ses crédits

Il y a deux boutiques : la boutique de saison et la boutique globale.

  • Boutique de saison — le mieux est d'acheter les équipements du palier le plus haut existant, ou les éclats de personnages si ces équipements ne sont pas encore disponibles.
  • Boutique globale — le mieux est d'acheter les orbes.

Crédits de promotion

Les étoiles rouges se posent au-dessus des étoiles jaunes. Si vous avez 7 étoiles rouges mais seulement 5 étoiles jaunes, 2 étoiles rouges sont inutiles jusqu'à ce que le personnage atteigne 7 étoiles jaunes.

Ne montez pas les étoiles rouges au-delà de vos étoiles jaunes. Gardez vos crédits noirs pour les personnages méta.

Les orbes étoiles rouges

Il y a 2 types d'orbes étoiles rouges :

  • x10 crédits de promotions noires — ouvrez-les en priorité.
  • Personnage en vedette + x1 crédit noir — évitez d'ouvrir sans vedette intéressante.

Pour les orbes élites, ouvrez-les uniquement quand un personnage qui vous intéresse est en vedette. Ne les ouvrez jamais sans vedette.

L'importance du positionnement

Focus sur le raid

Le raid est le mode de jeu le plus rentable, quel que soit votre niveau. Concentrez-vous sur les équipes de raid avant de monter d'autres équipes.
